# Keyboard Shortcuts

| Keys | Action |
|---|---|
| Ctrl/Cmd + S | Save |
| Ctrl/Cmd + Z | Undo |
| Ctrl/Cmd + Shift + Z, or Ctrl + Y | Redo |
| Ctrl/Cmd + D | Duplicate selected object |
| Delete / Backspace | Delete selected object |
| F | Focus the selected object (or the whole scene) |
| W / E / R | Move / Rotate / Scale tool |
| Ctrl/Cmd + P | Play / Stop |
| Esc | Stop play mode; close dialogs and menus |
| Ctrl/Cmd + K | Search (outside the editor) |
| F2 (in the Scene panel) | Rename |
| ↑ / ↓ (in the Scene panel) | Select previous / next object |
| ← / → (in the Scene panel) | Collapse / expand |

**Number fields:** type a value and press Enter, use ↑/↓ to step (Shift ×10, Alt ×0.1), or drag the X/Y/Z label sideways.

**Play mode:** W A S D or arrow keys to move, Space to jump, drag the view to look around.
