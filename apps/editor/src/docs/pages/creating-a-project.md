# Creating a Project

The **New Project** wizard has five steps.

## 1. Name
Any name up to 80 characters. You can rename a project later from its card (**⋯ → Rename**) or in **Project Settings**.

## 2. Type

| Type | What it's for |
|---|---|
| 3D Game | Characters, physics, collectibles, play mode |
| 2D Game (beta) | Side-on games. Uses the 3D engine with a locked orthographic view and flat "sprite" quads |
| 3D Interactive Experience | Walkthroughs and showcases |
| Empty Project | A camera and a light |

## 3. Platform
**Android**, **Windows** or **Cross-platform**. This sets defaults (for example touch controls and battery-friendly settings). Projects themselves are portable: a project made on a phone opens on a PC.

## 4. Performance profile

- **Battery Saver** — 30 FPS, no shadows, reduced resolution.
- **Balanced** — adapts to the device (30 FPS on phones, 60 on PCs).
- **Performance** — the best the device can do. Uses more power.
- **Custom** — choose a quality level. It is still capped by the device's capability.

You can change the profile later in **Project Settings**.

## 5. Template

| Template | Contents |
|---|---|
| Empty | Camera and sun |
| Basic 3D Scene | Ground, lights, a few shapes |
| Third Person | Controllable character, follow camera, obstacles and steps |
| First Person | Walk around a courtyard; drag to look |
| Platformer | Platforms, a moving platform and gems to collect |
| Simple Environment | Trees, rocks and a pond |
| Shrine of Lamps | The demo game with official assets |
| 2D Side-Scroller | Orthographic camera, blocks and coins |

Templates are original Mythic Bharat Studios content. What you build from them is yours.
