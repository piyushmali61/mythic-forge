# Animation

> **Not implemented in 0.1.**

What works today:

- Animations inside imported GLB/glTF/FBX files are **kept** when you import them (the import screen shows how many there are), so your files are ready when playback arrives.
- Simple motion can be made with the **Rotate** and **Bob** behaviours.

Planned for 1.x:

- Playing animation clips on imported characters
- Blending between idle, walk and run for the Player Controller
- A simple keyframe editor
